# Introduction

sideBar is an AI-powered productivity assistant that lives in your pocket.
It helps you capture notes, search the web, manage tasks, and more — all
through a conversational interface.

## What You Can Do

Use sideBar to:

- Chat with an AI assistant that can search the web, take notes, and answer questions
- Enable skills to unlock new capabilities
- Organize your thoughts with the built-in notes editor

## Getting Started

Open sideBar and start a conversation. The assistant will guide you from there.
