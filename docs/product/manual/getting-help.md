If something isn't working the way you expect, here are the best places to start.

## Ask the Assistant

sideBar can answer questions about sideBar itself. If you're not sure how a feature works or where to find something, just ask in [Chat](/manual/chat) e.g. "how do I add a memory?" or "what can Skills do?" are perfectly good questions.

## Check Settings → Skills

A lot of functionality in sideBar is powered by [Skills](/manual/skills). If a feature seems to be missing, it may just be that the relevant Skill isn't enabled. Settings → Skills is a quick first thing to check.

## The FAQ

The [FAQ](/faq/general) section of these docs covers common questions and known gotchas. If something is tricky or frequently misunderstood, it's probably in there.

## Report a Bug or Request a Feature

You can report bugs and request new features directly from [Chat](/manual/chat).
Just tell sideBar what's wrong or what you'd like, for example "I found a bug
with task recurrence" or "I'd love to be able to export notes as PDF". sideBar
will handle the rest. sideBar uses context from your conversation to fill in the
details and submits the report automatically. You'll get a confirmation with a
link to the issue once it's filed.


## Offline

Reading your existing content always works offline. Creating new notes, sending messages, or adding tasks requires a connection. If something isn't saving, check your connectivity first.
