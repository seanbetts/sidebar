## What it does

The Tasks skill gives sideBar full access to your tasks from Chat. You can
ask sideBar to create tasks, complete them, set due dates and recurrence,
add notes, and organise everything into projects and groups. It is the
fastest way to capture and manage what you need to do without leaving the
conversation.

## Actions

| Action | Description |
| --- | --- |
| Create task | Creates a new task, optionally in a project |
| List tasks | Lists tasks, optionally filtered by project or smart list |
| Search tasks | Searches across all your tasks by name or content |
| Rename task | Renames a task |
| Complete task | Marks a task as complete |
| Delete task | Permanently deletes a task |
| Set task due date | Sets or updates the due date on a task |
| Clear task due date | Removes the due date from a task |
| Defer task | Pushes a task's due date to a later date |
| Set task repeat | Sets a recurrence schedule on a task |
| Update task notes | Adds or updates the notes field on a task |
| Create project | Creates a new project |
| Rename project | Renames a project |
| Create group | Creates a new group to organise projects |
| Rename group | Renames a group |

## When sideBar uses it

When your request involves creating or managing tasks. Common triggers:

- Capturing something to do ("Remind me to call Sarah tomorrow")
- Completing or updating a task ("Mark my grocery run as done")
- Querying your task list ("What do I have due this week?")
- Planning ("Create tasks for each step of this project")
- Scheduling ("Push my dentist task to next Monday")

## Requirements

- **Tier:** Standard (included, no installation needed)
- **API key:** None required

## How to enable

The Tasks skill is enabled by default. To toggle it, go to **Settings → Skills**.

## Examples

> "Add a task to review the contract by Friday."

> "What tasks do I have due today?"

> "Mark everything in my Shopping project as done."

> "Create a project called 'Website Launch' and add tasks for each of the steps we just discussed."

> "Push all my overdue tasks to next week."
