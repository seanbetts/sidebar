## What it does

The Onboarding Coach helps you finish setup when you are partway through
onboarding. It focuses on the next action that matters most, whether that is
adding an API key, recovering a permission you skipped earlier, or moving on
to the first real outcome after setup.

## Actions

| Action | Description |
| --- | --- |
| Guide setup recovery | Explains the next onboarding step for your current state |
| Recover provider setup | Helps you reconnect or add an AI provider key |
| Recover permissions | Points you to the explicit location or notification recovery path |
| Explain next steps | Summarizes what is available now and what unlocks after setup |

## When sideBar uses it

sideBar uses the Onboarding Coach when your onboarding state is still
incomplete. It is designed for setup recovery and first-run guidance, not
general day-to-day chat once onboarding is complete.

That usually means the coach disappears after you either complete your first
real outcome or finish the discovery follow-up after setup.

## Requirements

- **Tier:** Standard (included, no installation needed)
- **API key:** None required for the guidance itself

## How to enable

The Onboarding Coach is enabled by default. To toggle it, go to
**Settings → Skills**.
