## What it does

The Files skill gives sideBar the ability to work with your files directly
from Chat. You can ask sideBar to find a file, read its contents, rename or
delete it, or pin it for quick access. sideBar can also search across all
your files by name or content, making it easy to locate something without
knowing exactly where it is.

## Actions

| Action | Description |
| --- | --- |
| Read file | Reads the contents of a file and brings them into the conversation |
| Search files | Searches across your files by name or indexed content |
| Browse files | Lists and navigates your file library |
| Rename file | Renames a file |
| Pin file | Pins a file to the top of your file list for quick access |
| Delete file | Permanently deletes a file and its index |

## When sideBar uses it

When your request involves a file you have saved in sideBar. Common triggers:

- Asking about the contents of a document ("What does my contract say about X?")
- Finding a file by what it contains ("Find the spreadsheet with Q3 figures")
- Managing your files ("Rename the PDF I uploaded yesterday", "Pin my tax return")
- Using a file as context for something else ("Based on my notes from last week...")

## Requirements

- **Tier:** Standard (included, no installation needed)
- **API key:** None required

## How to enable

The Files skill is enabled by default. To toggle it, go to **Settings → Skills**.

## Examples

> "What are the key terms in the contract I uploaded?"

> "Find any files related to my home insurance."

> "Rename 'scan-001.pdf' to 'Insurance Policy 2026'."

> "Pin my CV so I can find it easily."
