# Skills

Skills are modular capabilities you can enable or disable to control what the
assistant can do. Each skill unlocks a specific ability.

## How Skills Work

- Skills are toggled per-account in **Settings → Skills**
- Enabled skills are available in every conversation
- Some skills require a paid plan or an external account connection

## Skill States

A skill can be in one of the following states:

- **Enabled** — active and available to the assistant
- **Disabled** — installed but not currently active
- **Unavailable** — requires a plan upgrade or external connection to use

## Finding Your Skills

Ask the assistant "What skills do I have?" or visit **Settings → Skills** to
see your full skill inventory with current status.
