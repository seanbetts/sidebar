# Web Search

The Web Search skill lets the assistant search the live web to answer questions
that require current or real-time information.

## What It Does

When enabled, the assistant can:

- Search the web for recent news, facts, and answers
- Cite sources in its responses
- Follow up with refined searches to improve accuracy

## How to Enable

Go to **Settings → Skills** and enable Web Search. It is available on all plans.

## When the Assistant Uses It

The assistant uses web search automatically when your question requires
information it doesn't already know, such as current events or recent releases.
