## What file types does sideBar support?

sideBar accepts a wide range of formats:

- **Documents**: PDFs, Word documents, plain text
- **Images**: JPG, PNG, and other common image formats
- **Audio**: audio recordings and common audio formats
- **Video**: video files
- **Spreadsheets**: Excel workbooks and CSV files
- **Presentations**: PowerPoint and similar formats

See [Files](/manual/files) for the full list.

## How do I add a file?

Tap the **+** button in the Files tab to open the file picker and choose a file
from your device. You can also share files directly from other apps using the
sideBar Share extension. See [Widgets and Extensions](/manual/extensions) for
setup instructions.

## What is ingestion and how long does it take?

After you add a file, sideBar indexes its content so it can search and reference
it in conversations. This moves through three stages: **uploading**,
**processing**, then **ready**. You can watch the status update in real time on
the file card. Most files complete in seconds, though large documents may take
longer. If something goes wrong, the card shows an error with a **Retry** button.

## Can sideBar read and work with my files?

Yes. Once a file reaches the **ready** state its content is indexed and sideBar
can search and reference it during any conversation. You can also attach a
specific file to a chat message to give sideBar focused context on that file.

## Can I view files inside sideBar?

Yes, for many file types:

- **PDFs**: full-page viewer with page navigation and pinch-to-zoom
- **Spreadsheets**: scrollable grid view with column headers
- **YouTube videos**: in-app player alongside the extracted transcript
- **Images**: full-screen display
- **Text and Markdown**: rendered preview

## What is the difference between pinning and archiving a file?

Pinning keeps a file at the top of your list for quick access. Archiving moves
it out of the main view without deleting it; you can restore it at any time. The
number of archived files appears at the bottom of the list. Deleting a file is
permanent and also removes its index.

## Do files sync across my devices?

Yes. Files and their indexed content sync across all devices where you are signed
in to sideBar.

## Can I delete a file?

Yes. Tap the menu on any file card and choose **Delete**, or swipe left on the
file. Deletion is permanent and removes both the file and its index. You will be
asked to confirm before anything is removed.
