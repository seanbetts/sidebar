The sideBar design system is the source of truth for UI decisions across iOS,
macOS, and web. It documents the target state, how things should be built, not
the current state of the codebase. Current-state gaps are tracked in
[Implementation Gaps](./implementation-gaps).

## How This Is Organised

**Overview**: core principles, voice and content rules, system inheritance
policy, and working tools such as the feature checklist, component template,
and implementation gaps.

**Platform Strategy**: conventions specific to iPhone, iPad, Mac, web, and
widgets.

**Foundations**: the lowest-level building blocks, including colour, tokens,
typography, materials, iconography, and accessibility.

**Components**: the shared component library with usage rules.

**Patterns**: interaction and behavioural patterns such as navigation,
feedback, wait states, errors, authentication, onboarding, and AI assistant UI.

**Audits**: current-state snapshots of the codebase, updated as gaps are
closed.
